    Safety First

    กฎความปลอดภัย 4 ข้อ ห้ามละเมิด

    สนุกได้เต็มที่ แต่ต้องปลอดภัยทุกรอบ มาร์แชลประจำสนามมีสิทธิ์หยุดการขับทันทีหากฝ่าฝืน

    RULE 01

    หมวกกันน็อกตลอดเวลา

    สวมหมวก ถุงมือ และคาดเข็มขัดนิรภัยก่อนออกรถทุกครั้ง อุปกรณ์ยืมฟรีที่จุดจ่าย

    RULE 02

    เครื่องแต่งกายรัดกุม

    รองเท้ารัดส้นเท่านั้น ห้ามรองเท้าแตะ ผมยาวต้องรวบเก็บในหมวก ไม่ใส่ผ้าพันคอหรือเครื่องประดับห้อย

    RULE 03

    เชื่อฟังสัญญาณธง

    ธงเหลือง = ชะลอความเร็ว ธงแดง = หยุดทันที ธงหมากรุก = จบรอบ ทำตามสัญญาณมาร์แชลทุกจุด

    RULE 04

    ห้ามชนโดยเจตนา

    ห้ามปะทะ บล็อก หรือดันรถคู่แข่งออกนอกเส้นทาง ผู้ฝ่าฝืนถูกเชิญออกจากสนามโดยไม่คืนค่าบริการ
